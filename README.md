# Micro Learning Analytics Dashboard

Production-ready React dashboard scaffold built with Vite, TypeScript strict mode, Redux Toolkit + RTK Query, Tailwind CSS, React Router v6, and Jest + Testing Library.

## Install

```bash
npm install
```

## Run in development

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Run tests

```bash
npm run test
```

## Folder structure

```text
src/

    layout/
  pages/
    Home/
  routes/
  store/
    apis/
    modules/
  hooks/
  services/
  constants/
  styles/
  types/
  utils/

```

## Environment

Create a `.env` file based on `.env.example`:

```bash
VITE_BASE_URL=
VITE_API_BASE_URL=
```
